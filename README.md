# ShardPrime

ShardPrime enables scalable, distributed processing of real-time data feeds through a dynamically auto-scaling, cloud-agnostic cluster.

ShardPrime is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/minhokingkim/ShardPrime.git`
2. `cd ShardPrime`
3. Install in editable mode: `pip install -e .`

## Configuration

ShardPrime is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
